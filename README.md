# Graph Course — стартовый экран

Статическая верстка начального экрана для курса по графовой аналитике.

## Файлы

```text
index.html
assets/css/styles.css
assets/js/script.js
```

## Как запустить локально

Можно просто открыть `index.html` в браузере.

Или через Python:

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000
```

## Что уже есть

- стартовый экран курса;
- тёмная и светлая тема;
- переключатель темы с сохранением в `localStorage`;
- hero-блок;
- карточки разделов;
- блок прогресса;
- заготовка под следующую тему и checkpoint.
